Stand-in samples, generated by Sturm (tools/render_samples.c). They are NOT audio from any instrument.

  001-010   the ten noise slots (White, Pink, Green, Resonant 4K, Soft, Cicada, Buzzed, Chain Link, Grinder, 420 HighPass)
  367       the sine, one cycle
  "Sturm VS waves cycles.wav"   the 96 single-cycle wave slots (368-463), one cycle between cue points

The plugin plays the same sounds without these files; they ship in its SAMPLES folder so you can open, edit or overwrite them.
To replace a slot, overwrite its file here (keep the number at the start of the name), don't add a second file for the same slot.
